# Divyanshu Tomar - Portfolio Website

A creative and interactive portfolio website showcasing my work as a Software Engineer with experience in system engineering, fintech, and full-stack development.

## 🌐 Live Demo

Visit my portfolio: **[divyanshutomar.tech](https://divyanshu931.github.io/os_inner.io)**

## 📋 About

This is a retro OS-inspired portfolio website built with React and TypeScript. It features an interactive desktop environment with various applications including:
- **My Showcase** - Portfolio explorer
- **The Oregon Trail** - Classic game integration
- **Doom** - Game emulation
- **Scrabble** - Word game
- **Henordle** - Wordle variant
- **Credits** - Project information

## 📦 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/divyanshu931/os_inner.io.git
   cd os_inner.io
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm start
   ```
   The site will open at `http://localhost:3000`

## 🚀 Build & Deploy

1. **Build for production:**
   ```bash
   npm run build
   ```

2. **Deploy to GitHub Pages:**
   ```bash
   npm run deploy
   ```
